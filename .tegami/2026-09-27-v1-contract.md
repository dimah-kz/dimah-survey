### Keep submit hooks inside the store lock

A second submit of the same draft no longer runs `onSubmit` before the first write finishes. `createEditorClient()` defaults to the editor mount. SQL writes return the stored `updatedAt`, and a taken slug is `SLUG_TAKEN`. The app owns its tables and refreshes them with the FumaDB CLI. Reference schema files are exported for reading, not for importing into the running app. SQL tables are `dimah_survey` and `dimah_response`.
