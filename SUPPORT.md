# Support

## Documentation

Guides and the protocol reference are at <https://survey.dimah.dev>.

## Questions

Usage questions belong in
[GitHub Discussions](https://github.com/dimah-kz/dimah-survey/discussions).

## Bugs and feature requests

Use the issue forms. Blank issues are closed. Search open issues and
discussions before opening a new one.

## Security

Vulnerabilities go through a
[private advisory](https://github.com/dimah-kz/dimah-survey/security/advisories/new).
See [SECURITY.md](./SECURITY.md). Do not open a public issue.
