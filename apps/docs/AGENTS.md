# Docs

Fumadocs site for dimah-survey. Not a published package. Protocol checklists stay in `docs/agents/`; this app is the public documentation site.

Formatting and the `check-types` script follow the repository. `check-types` runs `next typegen` first because routes use Next's typed `LayoutProps` and `PageProps`. ESLint stays on 9 and TypeScript on 5.9 because `eslint-config-next` does not accept the catalog ESLint 10 and TypeScript 7. Do not add a local Prettier config.

`@/*` maps to `./src/*`. `.source` is generated by Fumadocs and is gitignored. The dev server uses port 3001 so it does not share the example app's port.
