Fill and editor have separate configuration types and share one `database`.
Only fill accepts response validation; only editor accepts publish hooks.

## Fill instance

```ts
import {
  APIError,
  SURVEY_ERROR_CODES,
  dimahSurvey,
  guardRespondent,
} from "@dimah-survey/server";

import { database } from "@/db";

export const fill = dimahSurvey({
  audience: "fill",
  database,
  guard: async (context) => {
    const session = context.request
      ? await getSession(context.request)
      : null;
    if (!session) {
      throw APIError.from("FORBIDDEN", SURVEY_ERROR_CODES.FORBIDDEN);
    }
    return guardRespondent(session.user.id)(context);
  },
});
```

[Database](/docs/database) creates `database` with `@dimah-survey/db`.
`getSession` is your application code.

Returning nothing from a fill guard is forbidden. `guardRespondent(id)` returns
`{ respondentId }`. `guardAnonymous()` opts into capability-based anonymous
responses and returns `{ anonymous: true }`.

### Lifecycle hooks

```ts
import type { FillHooks } from "@dimah-survey/server";
```

<AutoTypeTable path="packages/server/src/dimah-survey.ts" name="FillHooks" />

A resumed start and an idempotent resubmit skip their hooks. `on*` hooks may
abort a write; `after*` hooks run after storage and cannot roll it back. Keep
external side effects retry-safe. HTTP bodies cannot provide hooks.

## Editor instance

```ts
import {
  APIError,
  SURVEY_ERROR_CODES,
  dimahSurvey,
} from "@dimah-survey/server";

export const editor = dimahSurvey({
  audience: "editor",
  database,
  guard: async ({ request }) => {
    if (!request || !(await isEditor(request))) {
      throw APIError.from("FORBIDDEN", SURVEY_ERROR_CODES.FORBIDDEN);
    }
  },
});
```

`isEditor` is your application code. An editor guard returns nothing or throws.
Omitting it leaves the editor open to every caller that can reach the route.

## Browser clients

`createFillClient` and `createEditorClient` accept the same options. Only the
default `baseURL` differs.

```ts
import type { CreateSurveyClientOptions } from "@dimah-survey/react";
```

Browser methods take flat objects. `fill.api` and `editor.api` take `{ body }`
or `{ query }`, plus optional `headers` or `request` for guards. See
[Mount the server](/docs/integration).
