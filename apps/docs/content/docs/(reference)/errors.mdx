Failed requests return an HTTP status and JSON
`{ message, code?, questions? }`.

Throw with `APIError.from` and a code from `SURVEY_ERROR_CODES`. A plain
`Error` becomes `INTERNAL_ERROR`. Branch on `code`, never on `message`.

```ts
import {
  APIError,
  SURVEY_ERROR_CODES,
  isAPIError,
} from "@dimah-survey/server";

throw APIError.from("NOT_FOUND", SURVEY_ERROR_CODES.SURVEY_NOT_FOUND);
throw APIError.from("FORBIDDEN", SURVEY_ERROR_CODES.FORBIDDEN);
throw APIError.from("CONFLICT", SURVEY_ERROR_CODES.STALE_UPDATE);

if (isAPIError(error)) {
  console.log(error.code, error.message);
}
```

`isAPIError` is also exported from `@dimah-survey/core`. There is no
`UNAUTHORIZED` code. Reject an anonymous caller with `FORBIDDEN`.

## Error catalog

| `code`               | HTTP | When                                                                 |
| -------------------- | ---- | -------------------------------------------------------------------- |
| `NOT_FOUND`          | 404  | Path matches no route on this audience                               |
| `SURVEY_NOT_FOUND`   | 404  | Id or slug is missing, or the survey is not an active published read |
| `RESPONSE_NOT_FOUND` | 404  | Response id is missing                                               |
| `FORBIDDEN`          | 403  | `guard` rejected the caller, or the principal cannot touch the row   |
| `NOT_PUBLISHED`      | 409  | Start or resume without an active published document                 |
| `SURVEY_CLOSED`      | 409  | Start, partial save, or submit outside `opensAt` / `closesAt`        |
| `RESPONSE_LIMIT`     | 409  | `submitted` rows are already at `maxResponses`                       |
| `SLUG_TAKEN`         | 409  | Slug is already used by another survey                               |
| `STALE_UPDATE`       | 409  | `expectedUpdatedAt` does not match the stored row                    |
| `RESPONSE_CLOSED`    | 409  | The row status does not allow this write, or reopen is disabled      |
| `OPEN_DRAFT`         | 409  | This respondent already has a different open draft                   |
| `VALIDATION_ERROR`   | 400  | The payload failed schema checks. Read `message`                     |
| `VALIDATION_FAILED`  | 400  | The snapshot rejected the answers. Read `questions`                  |
| `INTERNAL_ERROR`     | 500  | Unhandled exception                                                  |

`SURVEY_NOT_FOUND` on `getPublishedSurvey` also covers a draft or archived
survey. The editor `getSurvey` uses the same code when the id is missing, and
returns the draft when the row exists.

## Validation failures

`VALIDATION_FAILED` adds `questions`: the SurveyJS question names that failed.
`message` lists those names. It is not a localized string.

```json
{
  "message": "Survey result is invalid: name, score",
  "code": "VALIDATION_FAILED",
  "questions": ["name", "score"]
}
```

`VALIDATION_ERROR` is a bad request body or query, such as a settings object
whose `closesAt` is not after `opensAt`. It has no `questions` array.

A resubmit that fails validation on an already submitted row is
`RESPONSE_CLOSED`, not `VALIDATION_FAILED`. The row is already closed. See
[Responses](/docs/responses).
