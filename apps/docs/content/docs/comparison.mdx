[SurveyJS](https://surveyjs.io/) renders the form either way. Authentication,
migrations, and Creator stay in your application. dimah-survey is the
[Better Auth](https://www.better-auth.com)–like server for publish and
responses.

| Concern                          | dimah-survey | SurveyJS alone |
| -------------------------------- | ------------ | -------------- |
| Publish                          | Included     | You build it   |
| Survey stored with each response | Included     | You design it  |
| Save, submit, and reopen         | Included     | You build it   |
| Fill and editor API              | Included     | You build it   |

Use SurveyJS alone when the renderer is enough. Skip dimah-survey when you
want a hosted survey product, or you are not using SurveyJS JSON.

## Outside this library

dimah-survey does not render questions, ship Creator, store uploaded files, or
provide accounts, dashboards, PDF export, or analytics.

SurveyJS Analytics or PDF tooling can use one published document together with
the `data` rows that point at it. Read older answers with the survey stored on
that response.
