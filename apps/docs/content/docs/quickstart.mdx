Publish a SurveyJS document, store it with `@dimah-survey/db`, and render the
frozen response.

### Install [step]

```npm
npm i @dimah-survey/server @dimah-survey/db @dimah-survey/react survey-core survey-react-ui fumadb
```

`survey-react-ui` renders the questions. Add the tables on
[Database](/docs/persistence).

### Create the server [step]

The guard reads your session. The browser cannot choose the respondent.

```ts title="lib/survey.ts"
import {
  APIError,
  SURVEY_ERROR_CODES,
  dimahSurvey,
  guardRespondent,
} from "@dimah-survey/server";

import { database } from "@/db";

export const editor = dimahSurvey({
  audience: "editor",
  database,
  guard: async ({ request }) => {
    const session = await getSession(request);
    if (!session) {
      throw APIError.from("FORBIDDEN", SURVEY_ERROR_CODES.FORBIDDEN);
    }
  },
});

export const fill = dimahSurvey({
  audience: "fill",
  database,
  guard: async (context) => {
    const session = await getSession(context.request);
    if (!session) {
      throw APIError.from("FORBIDDEN", SURVEY_ERROR_CODES.FORBIDDEN);
    }
    return guardRespondent(session.user.id)(context);
  },
});
```

`getSession` is your application. See [Security](/docs/security).

### Publish a SurveyJS document [step]

Saving writes `draftJson`. Publishing copies that draft to `publishedJson`.

```ts title="lib/welcome.ts"
import { isAPIError } from "@dimah-survey/server";

import { editor } from "./survey";

const definition = {
  title: "Welcome",
  pages: [
    {
      name: "welcome",
      elements: [
        { type: "text", name: "name", title: "Your name", isRequired: true },
        {
          type: "rating",
          name: "score",
          title: "How was it?",
          isRequired: true,
        },
      ],
    },
  ],
};

export async function ensureWelcomeSurvey() {
  try {
    await editor.api.getSurvey({ query: { id: "welcome" } });
  } catch (error) {
    if (!isAPIError(error) || error.code !== "SURVEY_NOT_FOUND") throw error;

    await editor.api.saveSurvey({
      body: { id: "welcome", slug: "welcome", draftJson: definition },
    });
    await editor.api.publishSurvey({ body: { id: "welcome" } });
  }
}
```

`getSurvey` throws `SURVEY_NOT_FOUND` when the row is missing.

### Create the browser client [step]

The fill view below is React. `createFillClient()` calls `/api/survey`.

```ts title="lib/fill-client.ts"
"use client";

import { createFillClient } from "@dimah-survey/react";

export const fillClient = createFillClient();
```

Browser methods take a flat object. `fill.api` takes `{ body }` or `{ query }`.

### Render the response snapshot [step]

```tsx title="components/fill.tsx"
"use client";

import { useSurveyResponse } from "@dimah-survey/react";
import dynamic from "next/dynamic";

import { fillClient } from "@/lib/fill-client";

import "survey-core/survey-core.min.css";

const Survey = dynamic(
  () => import("survey-react-ui").then((mod) => mod.Survey),
  { ssr: false },
);

export function Fill({ responseId }: { responseId: string }) {
  const { model, error, saveError, stale, reload } = useSurveyResponse({
    client: fillClient,
    responseId,
  });

  if (error) return <p>{error.message}</p>;
  if (!model) return null;

  return (
    <>
      {saveError ? <p>{saveError.message}</p> : null}
      {stale ? <button onClick={reload}>Reload</button> : null}
      <Survey model={model} />
    </>
  );
}
```

The hook builds a `Model` from `response.definition` and saves the full
`survey.data` on the next page. It does not render questions. Next.js loads
`<Survey>` in the browser; other React apps can import it directly.

### Start the response [step]

```tsx title="app/page.tsx"
import { Fill } from "@/components/fill";
import { ensureWelcomeSurvey } from "@/lib/welcome";
import { fill } from "@/lib/survey";

export default async function Page() {
  await ensureWelcomeSurvey();
  const response = await fill.api.startResponse({
    body: { surveyId: "welcome" },
  });

  return <Fill responseId={response.id} />;
}
```

This page is Next.js. Any server runtime calls `fill.api.startResponse` the
same way. The first call copies the published document onto the response.
Refreshing resumes that draft. A later publish leaves it unchanged.

## Frequently asked questions

<Accordions>

<Accordion title="Does refreshing this page create another response?">

Not for the same signed-in respondent. New surveys use `responses: "one-open"`,
so `startResponse` returns the existing draft. A different user gets a separate
row. Anonymous guards always insert. See [Settings](/docs/settings).

</Accordion>

<Accordion title="Does publishing a newer draft change this response?">

No. The first `startResponse` copies `publishedJson` onto that response. A
later publish changes only responses started after it.

</Accordion>

<Accordion title="Why does the Survey component load with next/dynamic?">

`survey-react-ui` needs a browser. The hook still runs in the client component
and builds the `Model` from `response.definition`. Other React setups can
import `<Survey>` directly.

</Accordion>
