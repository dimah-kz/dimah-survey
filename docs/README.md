# Documentation

Public guides and the protocol reference are published at
<https://survey.dimah.dev>.

The site source is [`apps/docs`](../apps/docs). From the repository root:

```bash
pnpm dev:docs
```

That serves the same content at <http://localhost:3001>.

[`docs/agents`](./agents) is the maintainer checklist for changing the
protocol. It is not the public manual.
